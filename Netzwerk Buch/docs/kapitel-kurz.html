        SkiTag ist ein Mietchip für das Skigebiet. Er schickt Notrufe mit Standort an die Bergbahn und kann die eigene Gruppe rufen, ohne Handy und ohne Handynetz. Diese Seite erklärt das Projekt ohne Vorwissen.

        Die Idee

        Wer auf der Piste stürzt, hat vielleicht kein Handy dabei oder keinen Empfang. Mit SkiTag genügt ein Knopf am Chip. Dafür braucht es ein eigenes kleines Funknetz am Berg, und um dieses Netz geht es in diesem Buch.

        Wie ein Notruf ankommt

        1. Knopf drücken: Die Person hält den Knopf 3 Sekunden. Danach bleiben 5 Sekunden zum Abbrechen.
        2. Chip sendet: Der Chip funkt den Notruf mit seiner Position über LoRa, eine Funktechnik für wenig Daten und große Entfernungen.
        3. Gateway leitet weiter: Ein Gerät an einer Station hört das Paket und reicht es an den Server weiter.
        4. Server entscheidet: Der Server prüft das Paket, legt den Notruf an und wählt den nächsten freien Mitarbeiter.
        5. Mitarbeiter wird alarmiert: Die App zeigt den Notruf, ein Tipp auf „Annehmen“ übernimmt ihn.
        6. Übernahme kommt zurück: Der Chip vibriert zweimal. Die Person weiß: Ein Mensch hat übernommen.

        Das lässt sich in Kapitel 1 Schritt für Schritt ansehen.

        Das System auf einen Blick

        Das Bild zeigt alle Teile und wo sie stehen, so wie es für den Betrieb geplant ist. Der Chip funkt zum Gateway am Berg, das Gateway reicht das Paket über Kabel an den Server bei KitzSki weiter, und der Server erreicht die Apps über Internet und Mobilfunk.

        Die wichtigsten Erkenntnisse

        • Eine Empfangsbestätigung (ACK) heißt nur, dass der Server den Notruf hat. Erst die Übernahme-Meldung (HELP 1) heißt, dass ein Mensch übernommen hat.
        • Am Berg entscheidet das Gelände über die Reichweite, nicht der Abstand.
        • Nach dem Modell braucht KitzSki 4 Gateways, mit Reserve rund 12. Gemessen ist das nicht.
        • Der Test ersetzt keinen Notruf: Im Ernstfall gilt 140.
