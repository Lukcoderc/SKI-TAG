      Auf dieser Seite

        SkiTag ist ein Mietchip, der im Skigebiet Notrufe mit Standort sendet, ohne Handy und ohne Handynetz. Dieses Buch erklärt das Netz dahinter: vom Knopf am Chip über Gateway und Server bis in die App der Bergbahn. Es folgt dem Weg des Signals, jedes Kapitel baut auf den vorigen auf.

        SkiTag in 5 Minuten Mit Kapitel 1 beginnen Häufige Fragen Glossar

        Das System auf einen Blick

        Der Chip funkt zum Gateway, das Gateway reicht das Paket über Kabel an den Server weiter, der Server entscheidet, und die App zeigt das Ergebnis.

        Wie sicher eine Aussage ist

        Jede Aussage trägt eine dieser Marken. In der Liste unten steht bei jedem Kapitel, wie oft jede Marke dort vorkommt. Auf echter Hardware ist noch nichts getestet.

        Fest
        Steht unverrückbar, etwa durch Gesetz oder Hardware.
        Entschieden
        Wir bauen es so, belegt ist es erst durch den Test.
        Geschätzt
        Gerechnet oder angenommen, nicht gemessen.
        Offen
        Noch nicht geklärt.

        Einstieg

        Wer nur den Überblick braucht oder eine bestimmte Antwort sucht, fängt hier an.
